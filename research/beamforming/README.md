# Beamforming Research

This study evaluates classical speech enhancement and beamforming on RIRs
generated by Acoustic Agent. It deliberately separates three systems that are
often confused:

1. **Single-channel enhancement baseline**: one microphone, raw mixture and a
   Wiener filter. A single microphone is not called beamforming.
2. **Local four-channel array**: a compact circular array using broadband
   Delay-and-Sum (DS), with either oracle RIR arrivals or SRP-PHAT DOA steering.
3. **Distributed synchronized microphones**: topology-independent whole-home
   microphone placement, TDOA localization, and classical fixed/adaptive
   beamformers.

## Protocol

- The target is `main_voice.wav`; the interferer is
  `background_speech.wav`.
- Target and interferer are rendered through independent RIRs before level
  calibration.
- Local-array estimated steering uses only a target-active calibration
  observation and SRP-PHAT.
- Distributed estimated steering uses GCC-PHAT TDOA and FloorPlan grid
  localization. The single-case experiment can use portal-routed propagation;
  the stratified benchmark uses measured synchronized TDOA directly.
- Distributed selection ranks source-room microphones first, then portal hops,
  observed target activity, and routed distance.
- Both same-room and cross-room interferers are evaluated.
- RIR simulation time is reported separately from enhancement speed. `RTF`
  covers beamforming or filtering only.

The adaptive benchmark uses separate observable calibration conditions:

- **Target-active**: target plus low-level sensor noise, used for TDOA and
  target spatial covariance.
- **Target-silent**: interfering speech, pink background noise, and sensor
  noise, used for noise spatial covariance.

No clean evaluation waveform is used to estimate beamformer weights. Intrusive
enhancement metrics use one fixed interference-free target image at the
calibrated reference microphone. The original dry source is retained as a
secondary denoising-plus-dereverberation diagnostic.

## Run

```bash
python -m research.beamforming.run \
  --study all \
  --quality preview \
  --floorplan-idx 0 \
  --distributed-nodes 8 \
  --subset-counts 2 4 6 8
```

Use `--study local` to run only the compact four-channel array, or
`--study distributed` to run only the synchronized FloorPlan microphones.

For a CUDA machine:

```bash
python -m research.beamforming.run \
  --quality simulation \
  --rt-accelerator cuda \
  --rt-precision float32 \
  --rt-cuda-device 0
```

Artifacts are written to `research/results/beamforming/`:

- `report.md`: compact experiment table.
- `summary.csv` and `summary.json`: machine-readable metrics and selections.
- `local-array/*.wav`: listening examples.
- `distributed/rir-cache/`: deterministic RIR cache for repeated sweeps.

`STOI` is optional. Install `pystoi` to populate that field; SNR and SI-SDR
remain dependency-free.

## Stratified Benchmark

The fixed benchmark uses five held-out FloorPlans for each of 4, 6, 8, 10, and
12 rooms: 25 layouts and 50 same-room/cross-room interference cases. The fixed
deployment policy keeps whole-home coverage near eight synchronized nodes:

| Rooms | Synchronized single microphones |
| ---: | ---: |
| 4 | 5 |
| 6 | 7 |
| 8 | 8 |
| 10 | 8 |
| 12 | 8 |

Algorithms:

- `best_single`: strongest calibrated single channel; not beamforming.
- `ds`: equal-weight TDOA Delay-and-Sum.
- `weighted_ds`: TDOA Delay-and-Sum weighted by target/noise calibration.
- `mvdr`: distortionless minimum-variance beamformer.
- `gev`: generalized-eigenvalue maximum-SNR beamformer with steering
  normalization.
- `mwf`: reference-channel multichannel Wiener filter.

Install the optional intrusive metrics and run:

```bash
pip install -e '.[research]'
python -m research.beamforming.run_benchmark \
  --room-counts 4 6 8 10 12 \
  --plans-per-room-count 5 \
  --quality preview
```

The run writes `details.csv`, aggregate CSV tables, `summary.json`, `report.md`,
listening examples, a parameter-validated checkpoint, and deterministic RIR
caches. Metrics include:

- SNR and SI-SDR improvement relative to the calibrated best single channel.
- PESQ, STOI, and SI-SDR against the delay-aligned clean target image at the
  reference microphone, plus dry-source-reference diagnostics.
- Same-room versus cross-room interference.
- TDOA room accuracy and position error.
- Processing real-time factor (`RTF`).

The checked-in aggregate result is in
[`evidence/stratified-preview-25/`](evidence/stratified-preview-25/README.md).
PESQ is useful here but should not be read alone: aggressive MVDR/GEV settings
can improve SNR while reducing SI-SDR or intelligibility.

## Complete Audio Front End

The complete benchmark adds dereverberation and compares three deployable
front ends under the same 25-layout split:

- one automatically selected microphone: raw and Wiener enhancement;
- one local four-channel circular array: DS, MVDR, MWF, WPE+MVDR,
  WPE+MWF, and WPD;
- synchronized distributed single microphones: weighted DS, MVDR, MWF,
  per-node WPE followed by MVDR/MWF, and TDOA-aligned WPD.

WPE uses a 32 ms STFT, a 24 ms prediction delay, and either five taps for the
compact array or ten independent taps per distributed node. Independent
prediction prevents a remote node's late direct arrival from being mistaken
for reverberation. WPD is retained as a stress baseline; it is not the default
distributed method.

```bash
python -m research.beamforming.run_frontend_benchmark \
  --room-counts 4 6 8 10 12 \
  --plans-per-room-count 5 \
  --quality preview \
  --output research/results/complete-frontend-preview-25
```

The first selected layout also receives WAV files for every pipeline. The full
run writes 700 rows covering 25 FloorPlans and 50 same-room/cross-room cases.
The checked-in evidence and interpretation are in
[`evidence/complete-frontend-preview-25/`](evidence/complete-frontend-preview-25/README.md).
The ranking is rechecked at `simulation` quality on one layout per room-count
stratum in
[`evidence/complete-frontend-simulation-5/`](evidence/complete-frontend-simulation-5/README.md).

Main result: local four-channel MWF is the most consistent enhancement chain,
improving SI-SDR in all 50 cases and winning 46. Distributed MWF also improves
all 50 cases and gives the highest average cross-room PESQ. WPE provides a
small dry-reference benefit but reduces the pure denoising score in this
short-utterance protocol, so it should remain optional.

## Fixed Whole-Home Deployment

The complete front-end benchmark above includes an oracle local-array upper
bound: its array is placed in the known target room. The fixed whole-home study
removes that assumption. Microphone positions are frozen before two target
rooms are sampled in every FloorPlan: one covered by a fixed array and one
without a fixed array.

See the complete protocol, system flowchart, results, and final deployment
recommendation in
[`WHOLE_HOME_DISTRIBUTED.md`](WHOLE_HOME_DISTRIBUTED.md).

The study compares:

- an oracle target-room single microphone and four-channel circular array;
- TDOA-routed fixed single microphones and fixed arrays;
- all synchronized distributed singles with MWF;
- a channel-budget-matched hybrid with one array and `N-4` singles;
- a coverage-preserving hybrid with all `N` singles plus one fixed array in
  4/6/8-room homes or two fixed arrays in 10/12-room homes.

Source emission gains are calibrated once at the target-room reference and
then shared by every deployment. This preserves distance, portal, wall, and
coverage differences instead of independently forcing every architecture to
the same input SNR.

```bash
python -m research.beamforming.run_whole_home_benchmark \
  --room-counts 4 6 8 10 12 \
  --plans-per-room-count 5 \
  --quality preview \
  --output research/results/whole-home-preview-25
```

The report separates array-covered and array-uncovered target rooms and writes
mean and P10 quality, TDOA room accuracy, same-room/cross-room interference,
hardware devices/channels, RTF, and listening WAV files. The oracle rows are
upper bounds; only `tdoa_routed_*`, `distributed_*`, and `*_hybrid_*` represent
fixed deployable systems. Checked-in evidence is available in
[`evidence/whole-home-preview-25/`](evidence/whole-home-preview-25/README.md).
